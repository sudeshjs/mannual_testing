# DemoBlaze Manual Testing Project

## 📌 Project Overview

This project is a **Manual Testing project** performed on the DemoBlaze e-commerce web application.

The main purpose of this project is to verify the functionality, navigation, UI, product modules, cart, login, signup, and order placement features of the application.

**Application:** DemoBlaze  
**Application URL:** https://www.demoblaze.com/  
**Application Type:** Web Application  
**Testing Type:** Manual Testing  
**Testing Approach:** Black Box Testing  

---

## 🎯 Testing Objectives

- Verify that the DemoBlaze website works as expected.
- Test important application functionalities.
- Identify functional and UI defects.
- Verify positive and negative test scenarios.
- Record actual and expected results.
- Prepare defect reports.
- Prepare a final test summary.

## 🐞 Defect Report

During testing, a defect was identified in the Cart module.

### Bug ID

**BUG_001**

### Bug Summary

**Place Order button is displayed when the cart is empty.**

### Steps to Reproduce

1. Open DemoBlaze.
2. Open the Cart.
3. Do not add any product.
4. Check the cart page.
5. Check the Place Order button.

### Expected Result

The Place Order button should be disabled or hidden when there are no products in the cart.

### Actual Result

The Place Order button is displayed even when the cart is empty.
